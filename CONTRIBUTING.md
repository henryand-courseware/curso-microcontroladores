# Contributing / Contribuciones

## English

- Use one file per topic.
- Prefer short pages with many examples.
- Keep headings consistent.
- Avoid committing large binaries; use links instead.

## Español

- Usa un archivo por tema.
- Prefiere páginas cortas con muchos ejemplos.
- Mantén consistencia en encabezados.
- Evita subir binarios pesados; mejor enlázalos.
